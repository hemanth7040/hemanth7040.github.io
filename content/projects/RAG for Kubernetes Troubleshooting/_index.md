Built a Retrieval-Augmented Generation (RAG) application that ingests Kubernetes troubleshooting documentation, converts document chunks into embeddings, stores vectors in Qdrant, and generates grounded responses using a locally hosted LLM via Ollama.

## Tech Stack

Python • LangChain • Ollama • Qwen2.5-Coder • Sentence Transformers • Qdrant • RAG

## Key Features

- Document loading and chunking
- Semantic embeddings generation
- Vector storage using Qdrant
- Semantic similarity search
- Context-aware prompt construction
- Grounded question answering using a local LLM
